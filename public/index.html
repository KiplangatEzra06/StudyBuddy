    Settings
    
      
    Back up or restore the study data saved in this browser.
    
      
    
        
        
        
      
    
      
    Imports merge with data already in this browser; existing records are kept when IDs match. Flashcards are deduplicated by deck and card text. Login credentials are never included in backups.
    
      
    
      
    
        
        
      
    
      
    
      
    Appearance
    
      
    Choose a theme. System follows your device preference and updates when it changes.
    
      
      
    
      
    Tutor privacy
    
      
    
    
          
    
        
    
    
    Flashcards are stored securely on the StudyBuddy server. Documents, classes, assignments, notes,
      quiz history, and timer sessions are stored in IndexedDB on this browser. AI generation and Tutor use the backend
      server; raw API keys stay server-side.
